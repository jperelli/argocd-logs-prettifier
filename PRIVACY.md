# Privacy policy

Argo CD Logs Prettifier runs entirely inside your browser.

- It reads the log lines already displayed by the Argo CD web UI on the sites you explicitly add in its options
  page, and re-renders them on that same page.
- It does not send any data anywhere: there are no analytics, no remote servers, no network requests of its own.
- The only data it stores is your preference for the structured view (on/off) and the list of Argo CD URLs you
  added, kept in Chrome's extension storage (synced with your Chrome profile if sync is enabled).
- Site access is requested per Argo CD instance when you add it and can be revoked at any time from the options
  page or from `chrome://extensions`.
